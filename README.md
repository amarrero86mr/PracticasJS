Una pequeña colección de ejercicios rápidos y simples para aprender y practicar JavaScript.

Acerca del proyecto
Este repositorio contiene ejercicios cortos enfocados en mejorar las bases de JavaScript mediante práctica constante.

Los objetivos principales son:

Practicar sintaxis y lógica
Aprender conceptos fundamentales de JavaScript
Experimentar con pequeños desafíos
Mantener constancia mientras aprendemos
Temas incluidos
Algunos de los temas que se practican en este repositorio:

Variables y tipos de datos
Funciones
Arrays y objetos
Bucles
Condicionales
Manipulación del DOM
Características de ES6+
Algoritmos básicos
